# Lorebook Groups / 世界书分组

一个不改动世界书原件的 SillyTavern 世界书分组扩展。

当前公开版本为 v0.1.0。扩展入口已经在 SillyTavern 1.18.0 中完成安装、更新、停用和重新启用验证；面板可以显示并搜索全部世界书，自动标注全局、角色、聊天或无绑定状态，并把同一本世界书安全地放进零个、一个或多个自定义组。你也可以在独立管理区新建、改名、排序、折叠或删除分组，通过“全选当前结果”批量加入或移出，或在电脑上把书名旁的手柄拖到另一组；这些操作都不会修改世界书原件。原生世界书列表下还提供按组浏览、原件启停和编辑入口，并在窄屏时与原生列表竖向排列。功能进度见[功能台账](docs/tasks.md)。

开发命令：

```bash
npm install
npm run check
npm run dev
```

安装时在 SillyTavern 的“扩展 → 安装扩展”中粘贴下面的仓库链接即可：

https://github.com/siyeliuyue0405/sillytavern-lorebook-groups

玩家只需要仓库链接，不需要安装 Node.js。稳定版本见 [v0.1.0 Release](https://github.com/siyeliuyue0405/sillytavern-lorebook-groups/releases/tag/v0.1.0)。
